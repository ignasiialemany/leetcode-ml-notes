Stable softmax

Stable softmax (shift by max)

Insight

softmax is invariant to shifting all logits. Subtract max(z) before exp so large values do not overflow.

Code

import numpy as np

def softmax(z):
    z = np.asarray(z, dtype=np.float64)
    z = z - np.max(z)
    e = np.exp(z)
    return e / e.sum()
