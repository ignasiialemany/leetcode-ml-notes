Stable softmax

ML Shift by max before exp

Insight

Softmax is invariant to shifting all logits. Subtract max(z) before exp so large values do not overflow.

$$\mathrm{softmax}(z)_i=\frac{e^{z_i-\max z}}{\sum_j e^{z_j-\max z}}$$

Small logits — both fine

Large logits — naive overflows, stable does not

Code

def softmax(z):
    z = np.asarray(z, dtype=np.float64)
    z = z - np.max(z)
    e = np.exp(z)
    return e / e.sum()
