Diffusion q_sample

ML Forward noising in closed form

Insight

You never need to chain t tiny noise steps. With a precomputed cumulative product ᾱ_t, jump straight to any timestep: mix clean data with Gaussian noise in one line.

$$x_t=\sqrt{\bar{\alpha}_t}\,x_0+\sqrt{1-\bar{\alpha}_t}\,\varepsilon,\quad\varepsilon\sim\mathcal{N}(0,I)$$

1. Progressive noising of a 1D signal

Same x₀ (faint green) with shared ε; as t grows, ᾱ_t → 0 and the curve dissolves into noise.

2. ᾱ_t schedule

Linear β → ᾱ_t = ∏(1-β_s). Signal weight falls; noise weight rises.

Code

def q_sample(x0, t, noise, alphas_cumprod):
    a_bar = alphas_cumprod[t]
    while a_bar.ndim < x0.ndim:
        a_bar = a_bar[..., None]
    return np.sqrt(a_bar) * x0 + np.sqrt(1.0 - a_bar) * noise
