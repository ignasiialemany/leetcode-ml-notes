LayerNorm

ML Normalize last-axis features, then affine

Insight

Per vector along the last dim: subtract mean, divide by std, then stretch with learnable \(\gamma,\beta\). Stabilizes scale across tokens / Q embeddings; the affine restores capacity so the network is not stuck at unit variance.

$$\hat x=\frac{x-\mu}{\sqrt{\sigma^2+\varepsilon}},\qquad y=\gamma\odot\hat x+\beta$$

1. Normalize last axis

Mean and variance are over \(D\) features for each row (token). After normalize, that vector sits near mean 0 / var 1.

Blue = raw \(x\); green = \(\hat x\).

2. Affine restores capacity

\(\gamma\) and \(\beta\) (shape \(D\)) re-scale and shift per channel so the layer can still represent arbitrary scales.

Code

def layer_norm(x, gamma, beta, eps=1e-5):
    mean = x.mean(axis=-1, keepdims=True)
    var = x.var(axis=-1, keepdims=True)
    x_hat = (x - mean) / np.sqrt(var + eps)
    return gamma * x_hat + beta
