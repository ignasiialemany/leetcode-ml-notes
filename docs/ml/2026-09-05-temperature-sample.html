Temperature sampling

ML Sample from softmax(z / T)

Insight

Sample from softmax(z / T). Small T stretches logit gaps (near-greedy); large T flattens toward uniform. Clamp tiny T to argmax.

How temperature reshapes the distribution

Empirical sample frequencies vs theory (T=1)

Code

def sample(z, T, rng):
    z = np.asarray(z, dtype=np.float64)
    if T <= 1e-8:
        return int(np.argmax(z))
    return int(rng.choice(len(z), p=softmax(z / T)))
