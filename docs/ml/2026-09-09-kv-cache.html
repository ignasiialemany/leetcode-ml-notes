KV-cache decode

ML Autoregressive attention reusing cached K/V

Insight

Cache K and V, not the attention matrix A. Each decode step only materializes a new query q_t (and the new key/value to append); scores are q_t against the full cached keys.

$$\mathrm{out}_t=\mathrm{softmax}\!\left(\frac{q_t K_{\le t}^\top}{\sqrt{d}}\right)V_{\le t},\quad K_{\le t}=[K_{\lt t};k_t],\; V_{\le t}=[V_{\lt t};v_t]$$

1. Cache grows; query is new

After each step the K/V tensors lengthen by one along the sequence axis. Past keys/values stay put — only q_t is computed fresh for attention.

2. Attention over cached positions

One decode step: softmax weights from q_t over all cached keys. Peak position highlighted; dashed line is uniform 1/T.

Code

def kv_cache_step(q_t, k_t, v_t, K, V):
    K_new = np.concatenate([K, k_t], axis=2)
    V_new = np.concatenate([V, v_t], axis=2)
    scale = np.sqrt(q_t.shape[-1])
    scores = (q_t @ np.swapaxes(K_new, -1, -2)) / scale
    out = softmax_last(scores) @ V_new
    return out, K_new, V_new
