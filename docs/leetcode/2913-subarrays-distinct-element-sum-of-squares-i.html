2913. Subarrays Distinct Element Sum of Squares I

Expand right, maintain distinct count

Insight

\(n \le 100\), so every subarray is fair game. Fix the left endpoint \(i\), grow the right endpoint \(j\), and keep a set of values seen in \([i,j]\). Each step costs \(O(1)\) amortized and contributes \(\lvert S\rvert^2\):

$$\sum_{0\le i\le j<n} \bigl(\#\{\textit{nums}[i..j]\}\bigr)^2$$

No need to rebuild the set from scratch for each \((i,j)\).

All subarrays for nums = [1, 2, 1]

Upper triangle only: cell (i,j) is the contribution of nums[i..j]. Six cells sum to \(1+4+4+1+4+1 = 15\).

Expand right for fixed i = 0

Start a fresh set for each left endpoint; as j walks right, insert and add \(\lvert S\rvert^2\).

Code

class Solution:
    def sumCounts(self, nums):
        n = len(nums)
        ans = 0
        for i in range(n):
            seen = set()
            for j in range(i, n):
                seen.add(nums[j])
                ans += len(seen) * len(seen)
        return ans
