20. Valid Parentheses

Stack: match closes to opens (LIFO)

Insight

A close bracket is only legal if it pairs with the most recent unmatched open of the same type. That is exactly a stack: push opens; on a close, the top must be the matching open — pop it — otherwise reject. When the scan ends the stack must be empty (no leftover opens). Cross nesting like ([)] fails because ] sees ( on top, not [.

Stack walk

For s = "([])" every close finds its twin on top, and the stack drains to empty.

Blue = push open; green = matched close (pop). Final empty stack ⇒ valid.

LIFO vs cross nesting

Same four characters, different order: ([]) is valid; ([)] is not. The second fails at ] because the stack top is still (.

Validity is not “counts balance”; it is “closes undo opens in reverse order.”

Code

class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        pair = {')': '(', ']': '[', '}': '{'}
        for ch in s:
            if ch in pair:
                if not stack or stack[-1] != pair[ch]:
                    return False
                stack.pop()
            else:
                stack.append(ch)
        return not stack
