921. Minimum Add to Make Parentheses Valid

Greedy balance counter: clamp at 0, adds + leftover open

Insight

Valid means two things: every prefix has at least as many ( as ), and the totals are equal. Track open = unmatched ( so far. Two kinds of defect exist, and each costs exactly one insertion:

  • A ) arriving when open = 0 can never be matched by anything to its right, so some ( must be inserted before it: adds += 1, and open stays at 0 (the inserted pair cancels).
  • Every ( still open at the end needs one ) appended.
$$\text{answer} = \text{adds} + \text{open}_{\text{end}}$$

Greedy is optimal because each insertion fixes at most one defect: one inserted ( rescues one orphan ), one inserted ) closes one leftover (. No stack is needed since there's only one bracket type, so the stack is just a counter.

Watch the counter bump against the floor

Scan ()))((()(. The counter rides above zero; each time a ) tries to push it below the floor we pay one ( instead. Whatever height is left at the end is paid in ).

Two orphan ) at positions 3 and 4 give adds = 2; the tail ((()( leaves 3 open. Answer \(2 + 3 = 5\): prepend (( and append ))) to get ((()))((()())).

Same thing without clamping: prefix minimum

Let \(P_i\) be the raw balance \(\#\texttt{(} - \#\texttt{)}\) of the first \(i\) characters. Clamping at 0 is the same as remembering how deep \(P\) ever dove. You must prepend \(-\min P\) opens to lift the whole curve onto the floor, which shifts the end to \(P_n - \min P\), the number of closes to append:

$$\text{answer} = -\min_i P_i + \big(P_n - \min_i P_i\big) = P_n - 2\min\!\big(0,\ \min_i P_i\big)$$

The dip to \(-2\) is the 2 orphan closes; lifting by 2 puts the end at \(1 + 2 = 3\). This view is handy when the question is "where should the inserts go": all the opens can go at the front and all the closes at the back.

Code

class Solution:
    def minAddToMakeValid(self, s: str) -> int:
        open_ = 0   # unmatched '(' so far
        adds = 0    # '(' we must insert for unmatched ')'
        for c in s:
            if c == '(':
                open_ += 1
            elif open_:
                open_ -= 1
            else:
                adds += 1
        return adds + open_

Complexity

One pass, two counters: \(O(n)\) time, \(O(1)\) space. Same skeleton as 20 with one bracket type, and the clamped counter is the single-path cousin of the \([lo, hi]\) band in 678.
