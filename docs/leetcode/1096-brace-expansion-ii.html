1096. Brace Expansion II

Recursive descent: brace union vs adjacent cartesian product

Insight

The expression is a grammar over sets of strings, not over single strings. Two operators:

$$ \begin{aligned} R(\{e_1, e_2, \ldots\}) &= R(e_1) \cup R(e_2) \cup \cdots \\ R(e_1\, e_2) &= \{ab \mid a\in R(e_1),\, b\in R(e_2)\} \end{aligned} $$

Comma inside braces is union. Adjacent factors are a cartesian product with concatenation. Recursive descent keeps a current product accumulator (start with \(\{\varepsilon\}\)). On {, recurse; on ,, push the current product into the union list and reset; on a letter, product with that singleton; on }, union the parts and return. Sort the final set.

Visual

Example "{a,b}{c,{d,e}}": left factor unions to \(\{a,b\}\), right factor unions to \(\{c,d,e\}\), adjacency multiplies them.

Adjacent factors multiply (×); commas inside { } take union (∪).

Example "{{a,z},a{b,c},{ab,z}}": three top-level union branches; branch 2 is itself a product a × {b,c}. Dedupe across branches, then sort.

Top-level braces = union of branches; each branch may still contain products.

Code

from typing import List

class Solution:
    def braceExpansionII(self, expression: str) -> List[str]:
        def product(left, right):
            if not left: return set(right)
            if not right: return set(left)
            return {a + b for a in left for b in right}

        def parse(i):
            unions = []
            cur = {""}
            n = len(expression)
            while i < n:
                c = expression[i]
                if c == "{":
                    inner, i = parse(i + 1)
                    cur = product(cur, inner)
                elif c == "}":
                    unions.append(cur)
                    out = set()
                    for part in unions:
                        out |= part
                    return out, i + 1
                elif c == ",":
                    unions.append(cur)
                    cur = {""}
                    i += 1
                else:
                    cur = product(cur, {c})
                    i += 1
            unions.append(cur)
            out = set()
            for part in unions:
                out |= part
            return out, i

        result, _ = parse(0)
        return sorted(result)
