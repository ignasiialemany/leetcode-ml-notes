3727. Maximum Alternating Sum of Squares

Sort and assign by magnitude: larger half of the squares on + slots, smaller half on − slots

Insight

The score is

$$ \text{score} = \sum_{i} (-1)^i\, a_i^2 , $$

so each element only shows up as \(a_i^2\), and the sign comes from the slot it lands in, not from its neighbours. Signs in the input disappear once squared, so \(-3\) and \(3\) are the same thing here. With \(n\) elements there are \(\lceil n/2 \rceil\) plus slots (even indices) and \(\lfloor n/2 \rfloor\) minus slots (odd indices).

Once you know which squares go to \(+\) and which go to \(-\), the order inside each group doesn't matter. Swap argument: if some square \(p\) on a \(+\) slot is smaller than some square \(q\) on a \(-\) slot, swapping them changes the score by \((q - p) - (p - q) = 2(q-p) > 0\). So at the optimum every \(+\) square is \(\ge\) every \(-\) square. Sort the squares, put the bottom \(\lfloor n/2 \rfloor\) on minus and the rest on plus:

$$ \text{ans} = \sum_{j \ge \lfloor n/2 \rfloor} s_j \; - \sum_{j < \lfloor n/2 \rfloor} s_j, \qquad s = \operatorname{sort}(a_i^2). $$

Values reach \(n \cdot (4\cdot10^4)^2 = 1.6\cdot10^{14}\), so in C++/Java you need 64-bit ints. Python's ints are fine.

Split the sorted squares

Both examples. Left: [1, 2, 3] has two plus slots and one minus slot, so the smallest square 1 is subtracted: \(13 - 1 = 12\). Right: [1, −1, 2, −2, 3, −3] squares to [1, 1, 4, 4, 9, 9]. The bottom three are subtracted and the top three added: \(22 - 6 = 16\). The two 4s fall on opposite sides of the split.

Checked against every ordering

Scores of all 720 orderings of [1, −1, 2, −2, 3, −3]. The sort-and-split value of 16 is exactly the right edge of the distribution. The given order scores 0.

Code

from typing import List

class Solution:
    def maxAlternatingSum(self, nums: List[int]) -> int:
        squares = sorted(x * x for x in nums)
        m = len(squares) // 2          # number of − slots (odd indices)
        return sum(squares[m:]) - sum(squares[:m])

Complexity

\(O(n \log n)\) time for the sort and \(O(n)\) extra space for the squares. Counting sort over \(|x| \le 4\cdot10^4\) would make it \(O(n + V)\), but you don't need it.
