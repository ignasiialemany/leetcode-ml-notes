1401. Circle and Rectangle Overlapping

Clamp to AABB, then radius check

Insight

A circle overlaps an axis-aligned rectangle iff the distance from the circle center \(C=(c_x,c_y)\) to the nearest point on the rect is at most \(r\). That nearest point is just the center clamped into the box:

$$ \begin{aligned} N_x &= \mathrm{clamp}(c_x,[x_1,x_2]) = \min(\max(c_x,x_1),x_2) \\ N_y &= \mathrm{clamp}(c_y,[y_1,y_2]) = \min(\max(c_y,y_1),y_2) \\ \text{overlap} &\iff (N_x-c_x)^2 + (N_y-c_y)^2 \le r^2. \end{aligned} $$

Three geometries fall out of the same clamp: center outside an edge (\(N\) on that side), near a corner (\(N\) is the corner), or inside (\(N=C\), distance \(0\)).

Visual

Shared AABB \([0,0]\times[4,3]\). Dashed segment is \(C\to N\); orange square marks the clamped nearest point.

Clamp the center into the rect, then test \(dx^2+dy^2 \le r^2\) — one formula covers edge, corner, and interior.

Code

class Solution:
    def checkOverlap(
        self,
        radius: int,
        xCenter: int,
        yCenter: int,
        x1: int,
        y1: int,
        x2: int,
        y2: int,
    ) -> bool:
        # Nearest point on the axis-aligned rect to the circle center (clamp).
        nx = min(max(xCenter, x1), x2)
        ny = min(max(yCenter, y1), y2)
        dx = nx - xCenter
        dy = ny - yCenter
        return dx * dx + dy * dy <= radius * radius
