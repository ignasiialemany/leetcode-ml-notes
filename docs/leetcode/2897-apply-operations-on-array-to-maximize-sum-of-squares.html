2897. Apply Operations on Array to Maximize Sum of Squares

Bit counting: AND/OR preserves per-bit counts, stack bits greedily into k numbers

Insight

Look at one bit position. If both \(a\) and \(b\) have it, both keep it; if neither, neither; if exactly one has it, after the operation the OR side has it and the AND side doesn't. So the operation never creates or destroys a bit, it only moves it. The invariant is the column count \(c_b\) = how many numbers have bit \(b\), and every redistribution of those bits is reachable.

Squares are convex: moving a bit worth \(2^b\) from a smaller number to a larger one changes the sum by

$$ (a+2^b)^2 + (s-2^b)^2 - a^2 - s^2 = 2\cdot 2^b\,(a - s) + 2\cdot 4^b > 0 \quad (a \ge s),$$

so you always want the bits piled as high as possible. Greedy: build the first number from one copy of every bit with \(c_b > 0\), decrement, repeat \(k\) times. Reduce mod \(10^9+7\) only after squaring each built value.

Columns are invariant, rows get restacked

Example 1, nums = [2, 6, 5, 8] with \(k=2\). Each column keeps its count of ones; pushing them all to the top rows gives 15 and 6, so the answer is \(225 + 36 = 261\).

Checked against every reachable state

A BFS over all 200 arrays reachable from [2, 6, 5, 8] (top-2 squares on the x axis). The greedy stacking lands exactly on the maximum, 261.

Code

class Solution:
    def maxSum(self, nums, k):
        MOD = 10**9 + 7
        cnt = [0] * 31
        for x in nums:
            for b in range(31):
                if x >> b & 1:
                    cnt[b] += 1
        ans = 0
        for _ in range(k):          # build the biggest number from the remaining bits
            v = 0
            for b in range(31):
                if cnt[b]:
                    cnt[b] -= 1
                    v |= 1 << b
            ans = (ans + v * v) % MOD
        return ans

Complexity

\(O(31\,(n + k))\) time and \(O(31)\) extra space.
