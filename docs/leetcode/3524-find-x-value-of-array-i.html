3524. Find X Value of Array I

Subarray product mod k (tiny modulus)

Insight

Keeping any non-empty contiguous piece is exactly “count all subarrays”. With \(n\le 10^5\) you cannot enumerate ends. But \(k\le 5\), so products only matter as remainders in \(\{0,\ldots,k-1\}\).

Let \(\mathrm{dp}[r]\) = number of subarrays ending at the previous index whose product \(\equiv r\pmod k\). At index \(i\) with \(a=a_i\bmod k\):

$$ \begin{aligned} \mathrm{ndp}[a] &\mathrel{+}= 1 &&\text{(singleton }[a_i]\text{)},\\ \mathrm{ndp}[(r\cdot a)\bmod k] &\mathrel{+}= \mathrm{dp}[r] &&\text{for every prior }r. \end{aligned} $$

Then add \(\mathrm{ndp}\) into \(\mathrm{result}\) and set \(\mathrm{dp}\leftarrow\mathrm{ndp}\). Total \(O(nk)\).

Visual

Code

from typing import List

class Solution:
    def resultArray(self, nums: List[int], k: int) -> List[int]:
        result = [0] * k
        dp = [0] * k
        for x in nums:
            x %= k
            ndp = [0] * k
            ndp[x] += 1
            for r in range(k):
                if dp[r]:
                    ndp[(r * x) % k] += dp[r]
            for r in range(k):
                result[r] += ndp[r]
            dp = ndp
        return result
