2778. Sum of Squares of Special Elements

Divisor scan: indices i with n % i == 0

Insight

Special depends only on the index, never the value: \(i\) is special iff \(i \mid n\). So the answer is $$\sum_{i \mid n} \text{nums}_i^2$$ A linear scan is \(O(n)\); iterating divisor pairs up to \(\sqrt n\) gives \(O(\sqrt n)\). Watch the 1-indexing.

Which indices count

n = 6 has divisors 1, 2, 3, 6; indices 4 and 5 are skipped regardless of how large their values are.

Code

class Solution:
    def sumOfSquares(self, nums):
        n = len(nums)
        return sum(nums[i-1]**2 for i in range(1, n+1) if n % i == 0)
