3550. Smallest Index With Digit Sum Equal to Index

Linear scan: digit_sum(value) vs index

Insight

Walk indices left to right. For each \(i\), compute the sum of decimal digits of \(\mathrm{nums}[i]\). The answer is the first \(i\) where that sum equals \(i\); if none, \(-1\). No fancy structure — \(n\le 100\) and values \(\le 1000\), so a plain loop wins.

Digit sum vs index

Example nums=[1,10,11]: digit sums are \(1,1,2\). Index \(0\) fails (\(1\neq 0\)); index \(1\) matches (\(1=1\)) → return \(1\). Index \(2\) would also match but we want the smallest.

Blue = digit sum of the value; orange = the index. First place they meet is the answer.

Code

class Solution:
    def smallestIndex(self, nums: List[int]) -> int:
        def digit_sum(x: int) -> int:
            s = 0
            while x:
                s += x % 10
                x //= 10
            return s
        for i, v in enumerate(nums):
            if digit_sum(v) == i:
                return i
        return -1
