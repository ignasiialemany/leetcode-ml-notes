3904. Smallest Stable Index II

Prefix max + suffix min

Insight

Score at i is max(prefix≤i)−min(suffix≥i). Build pref L→R and suf R→L, then first i with pref[i]-suf[i]≤k.

Visual

$$\mathrm{score}(i)=\max(nums[0..i])-\min(nums[i..n-1])$$

Pattern

Prefix max + suffix min

Code

class Solution:
    def firstStableIndex(self, nums, k):
        n = len(nums)
        pref, suf = [0]*n, [0]*n
        pref[0] = nums[0]
        for i in range(1, n):
            pref[i] = max(pref[i-1], nums[i])
        suf[-1] = nums[-1]
        for i in range(n-2, -1, -1):
            suf[i] = min(suf[i+1], nums[i])
        for i in range(n):
            if pref[i] - suf[i] <= k: return i
        return -1
