940. Distinct Subsequences II

Distinct subsequences of one string

Insight

No target string. Keep ends[c]=# distinct subs ending with c. On c: ends[c]=sum(ends)+1 (overwrite). That is 2*total+1−old_ends[c] in disguise.

Pattern

Distinct subsequences of one string

Code

class Solution:
    def distinctSubseqII(self, s):
        MOD = 10**9 + 7
        ends = [0] * 26
        for ch in s:
            i = ord(ch) - ord('a')
            ends[i] = (sum(ends) + 1) % MOD
        return sum(ends) % MOD
