1658. Minimum Operations to Reduce X to Zero

Sliding window: longest middle sum = total−x (complement of min prefix+suffix)

Insight

You may only delete from the left or right end. A sequence of such deletes that sums to \(x\) is exactly a prefix plus a suffix whose values add to \(x\). Flip the picture: the elements you do not delete form one contiguous middle. Minimizing deletions is the same as maximizing that middle’s length, subject to

$$ \sum_{\text{middle}} = \mathrm{total} - x. $$

So search for the longest subarray with sum \(\mathrm{total}-x\). Then

$$ \mathrm{answer} = \begin{cases} n & \text{if }\mathrm{total}=x,\\ n - L & \text{if a middle of length }L\text{ exists},\\ -1 & \text{otherwise}. \end{cases} $$

All \(a_i\ge 1\), so a shrink-only sliding window finds that longest middle in \(O(n)\).

Visual

Example \(\mathrm{nums}=[1,1,4,2,3]\), \(x=5\): \(\mathrm{total}=11\), target \(=6\). Longest middle is \([1,1,4]\) (len \(3\)) → answer \(5-3=2\) (delete the right end \([2,3]\)).

Removing only from both ends so values sum to \(x\) ≡ keep the longest contiguous middle with sum \(=\mathrm{total}-x\).

Sliding window on \(\mathrm{nums}=[3,2,20,1,1,3]\), \(x=10\): target \(=20\). Expand right, shrink left while sum \(>\) target; the only hit is \([20]\) (len \(1\)) → ops \(=6-1=5\).

Green step = current window sum equals the target; dashed line marks best length so far.

Code

from typing import List

class Solution:
    def minOperations(self, nums: List[int], x: int) -> int:
        total = sum(nums)
        if total < x:
            return -1
        if total == x:
            return len(nums)
        target = total - x
        n = len(nums)
        best = -1
        left = 0
        s = 0
        for right, v in enumerate(nums):
            s += v
            while s > target and left <= right:
                s -= nums[left]
                left += 1
            if s == target:
                best = max(best, right - left + 1)
        return -1 if best < 0 else n - best

\(O(n)\) time, \(O(1)\) extra space. Positives make the shrink-only window correct for “longest sum \(=\mathrm{target}\)”.
