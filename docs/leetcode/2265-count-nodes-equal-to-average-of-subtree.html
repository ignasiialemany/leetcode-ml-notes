2265. Count Nodes Equal to Average of Subtree

Post-order DFS · (sum, size)

Insight

Average needs both subtree sum and subtree size. Post-order DFS returns \((\textit{sum}, \textit{size})\) from each child; combine with the current node, then check \(\textit{val} = \lfloor \textit{sum}/\textit{size} \rfloor\). One pass, \(O(n)\).

Post-order annotations

Example \([4,8,5,0,1,\text{null},6]\): green nodes match. Node \(8\) is the only miss — \(\lfloor 9/3 \rfloor = 3 \neq 8\). Answer \(= 5\).

Each label is the \((\textit{sum}, \textit{size})\) pair the DFS returns for that subtree.

Code

class Solution:
    def averageOfSubtree(self, root: Optional[TreeNode]) -> int:
        ans = 0
        def dfs(node):
            nonlocal ans
            if not node:
                return 0, 0
            ls, ln = dfs(node.left)
            rs, rn = dfs(node.right)
            s, n = ls + rs + node.val, ln + rn + 1
            if s // n == node.val:
                ans += 1
            return s, n
        dfs(root)
        return ans
