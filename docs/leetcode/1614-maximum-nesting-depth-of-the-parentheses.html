1614. Maximum Nesting Depth of the Parentheses

Running paren depth counter

Insight

You only need the deepest nest level, not the matching contents. Digits and operators are noise. A single counter is enough: ( adds one, ) subtracts one, and the answer is the highest value the counter ever reaches. A stack would work, but it stores nothing you actually need.

Depth timeline

For s="(1+(2*3)+((8)/4))+1", the digit 8 sits inside three open parentheses. The running depth peaks at 3 right when that third ( opens.

Blue marks opens, amber marks closes. The curve is the depth after each character; the dashed line is the answer.

Counter rules

Ignore every character that is not a parenthesis. Update on the two that matter, keep a running max.

Because the string is a valid VPS, the counter never goes negative and ends at zero — you do not need extra validation.

Code

class Solution:
    def maxDepth(self, s: str) -> int:
        depth = ans = 0
        for c in s:
            if c == "(":
                depth += 1
                if depth > ans:
                    ans = depth
            elif c == ")":
                depth -= 1
        return ans
