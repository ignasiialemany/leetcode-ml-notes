1477. Find Two Non-overlapping Sub-arrays Each With Target Sum

Sliding window + prefix-min pairing

Insight

Need two non-overlapping subarrays each summing to \(\textit{target}\), minimize total length. Because \(\textit{arr}[i]\ge 1\), each end \(r\) has at most one start with that sum — a sliding window finds it in \(O(n)\). Keep \(\textit{prefix}[i]=\) min window length ending strictly before \(i\). For a window ending at \(r\) with start \(s\), try \(\textit{best}[r]+\textit{prefix}[s]\). Answer is the min over \(r\), or \(-1\).

Visual

Example \(\textit{arr}=[7,3,4,7]\), \(\textit{target}=7\): windows of lengths \(1,2,1\). Best non-overlapping pair is the two ends \(\rightarrow 1+1=2\).

Positives give a unique window per end; prefix-min turns “best earlier partner” into \(O(1)\).

Sketch

# best[r] = len of unique target-sum window ending at r (or ∞)
# prefix[i] = min best ending in [0, i)
# ans = min_r best[r] + prefix[start(r)]

\(O(n)\) time, \(O(n)\) space.
