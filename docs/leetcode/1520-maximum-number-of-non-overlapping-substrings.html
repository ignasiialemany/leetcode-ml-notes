1520. Maximum Number of Non-Overlapping Substrings

Character-closed intervals → greedy earliest-end

Insight

A valid substring must be closed under characters: if it contains \(c\), it must cover every occurrence of \(c\). So each letter \(c\) suggests an interval \([\textit{first}[c],\textit{last}[c]]\), then expand until no letter inside reaches outside. At most 26 such intervals (keep only representatives that start at their own letter’s first index). They nest or are disjoint — never partially overlap — so classic interval scheduling works: sort by end, greedily take non-overlapping. Nesting also makes max count = min total length.

Visual

Example \(s=\) adefaddaccc: closed(a) swallows e/f into one chunk; picking the tiny closed pieces e, f, ccc instead gives three substrings.

Expand each letter’s [first, last] to a closed interval, then earliest-end greedy among ≤26 candidates.

Sketch

# first/last per letter → expand to closed intervals (≤26)
# keep only intervals that start at their letter's first index

\(O(n)\) time (26·n expand), \(O(1)\) extra beyond the answer.
