1807. Evaluate the Bracket Pairs of a String

Hash map + single scan (keyed substitution)

Insight

There is no nesting, so the grammar is just literal text interleaved with (key) tokens. Build a hash map from knowledge, then walk s once: on (, take characters until ), append map.get(key, "?"), and continue after the close. Unknown keys become ?. Everything else is copied as-is.

Scan + replace

Example s="(name)is(age)yearsold" with name→bob, age→two: each parenthesized key is one dictionary lookup; the letters outside brackets never change.

Top: the lookup table. Bottom: each (key) token becomes its value; plain text passes through → bobistwoyearsold.

Code

class Solution:
    def evaluate(self, s: str, knowledge: List[List[str]]) -> str:
        mp = {k: v for k, v in knowledge}
        out = []
        i, n = 0, len(s)
        while i < n:
            if s[i] == '(':
                j = i + 1
                while s[j] != ')':
                    j += 1
                key = s[i + 1 : j]
                out.append(mp.get(key, '?'))
                i = j + 1
            else:
                out.append(s[i])
                i += 1
        return ''.join(out)
