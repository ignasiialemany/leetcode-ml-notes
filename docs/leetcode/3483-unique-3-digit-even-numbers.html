3483. Unique 3-Digit Even Numbers

Enumerate under tiny n

Insight

\(n \le 10\), so just generate length-3 permutations of the digit multiset. Keep those with hundreds \(\neq 0\) and units even; drop formed values into a set. No digit DP.

Enumerate & filter

Example digits=[1,2,3,4]: twelve distinct even numbers (e.g. 124, 132, …, 432). Rejects are leading zero, odd units, or reusing a copy.

Filter \(a \neq 0\) and \(c\) even; count unique \(100a+10b+c\).

Code

from itertools import permutations
from typing import List

class Solution:
    def totalNumbers(self, digits: List[int]) -> int:
        seen = set()
        for a, b, c in permutations(digits, 3):
            if a and c % 2 == 0:
                seen.add(100 * a + 10 * b + c)
        return len(seen)
