32. Longest Valid Parentheses

Stack of indices: longest valid paren substring

Insight

You are not checking whether the whole string is valid — you want the longest substring that is. Keep a stack of indices, seeded with sentinel -1. Push on (. On ): pop; if the stack empties, this close is unmatched — push i as the new base. Otherwise the candidate length is i - stack[-1] (distance to the new top). Track the max.

Walk on )()())

Index 0 is an unmatched close (new base). The run from 1..4 is ()() — length 4. The final ) resets the base again.

After each successful pop, length = current index minus the new stack top.

Why the sentinel −1?

The sentinel is the imaginary index before the current candidate. When a match leaves only -1 (or an unmatched open) on the stack, subtraction gives the full span. An unmatched ) that empties the stack becomes the next sentinel.

Same idea as a LIFO match, but the values on the stack are positions so you can measure length.

Code

class Solution:
    def longestValidParentheses(self, s: str) -> int:
        stack = [-1]
        best = 0
        for i, c in enumerate(s):
            if c == '(':
                stack.append(i)
            else:
                stack.pop()
                if not stack:
                    stack.append(i)
                else:
                    best = max(best, i - stack[-1])
        return best

Complexity

One pass: \(O(n)\) time, \(O(n)\) stack in the worst case (all opens).
