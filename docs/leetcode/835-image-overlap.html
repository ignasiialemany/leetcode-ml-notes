835. Image Overlap

Count votes for a relative transform

Insight

Every pair of ones \((p_1, p_2)\) votes for one translation vector \(p_1 - p_2\). The vector with the most votes is the best overlap. With \(n \le 30\), pairing the ones beats sliding the full matrix over all shifts.

Visual

Example 1: shift img1 by \(+1\) row and \(+1\) column. Three ones land on ones in img2.

Same three pairs cast the same \((\Delta r, \Delta c)\) vote — that count is the answer.

Code

from collections import Counter
from typing import List


class Solution:
    def largestOverlap(self, img1: List[List[int]], img2: List[List[int]]) -> int:
        n = len(img1)
        ones1 = [(r, c) for r in range(n) for c in range(n) if img1[r][c]]
        ones2 = [(r, c) for r in range(n) for c in range(n) if img2[r][c]]
        if not ones1 or not ones2:
            return 0
        cnt = Counter((r1 - r2, c1 - c2) for r1, c1 in ones1 for r2, c2 in ones2)
        return max(cnt.values())
