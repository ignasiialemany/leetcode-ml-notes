2472. Maximum Number of Non-overlapping Palindrome Substrings

Greedy earliest palindrome of length k or k+1

Insight

Maximize the count of non-overlapping palindromic substrings of length \(\ge k\). Any longer palindrome contains a palindrome of length \(k\) or \(k+1\), so those two lengths are enough. Scan left→right; at index \(i\) try \([i,i+k)\) then \([i,i+k+1)\); on a hit, take it and jump past its end (earliest-end greedy).

Visual

Example \(s=\) abaccdbbd, \(k=3\): take aba, skip past cc, then take dbbd → answer 2.

Only hunt length \(k\) and \(k+1\); jump past each pick so the next scan starts after its end.

Code

class Solution:
    def maxPalindromes(self, s: str, k: int) -> int:
        n = len(s)

        def is_pal(l: int, r: int) -> bool:
            while l < r:
                if s[l] != s[r]:
                    return False
                l += 1
                r -= 1
            return True

        ans = 0
        i = 0
        while i <= n - k:
            if is_pal(i, i + k - 1):
                ans += 1
                i += k
            elif i + k < n and is_pal(i, i + k):
                ans += 1
                i += k + 1
            else:
                i += 1
        return ans
