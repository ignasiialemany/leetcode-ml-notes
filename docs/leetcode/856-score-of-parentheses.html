856. Score of Parentheses

Depth counting: innermost () at depth d adds 2^d

Insight

The rules are \(\texttt{()} = 1\), \(AB = A + B\), \((A) = 2A\). Concatenation is plain addition and wrapping is multiplication by 2 — and multiplication distributes over addition: \(2(A+B) = 2A + 2B\). So push every "×2" all the way down until it hits an atom. The only atoms are the innermost () pairs, and each one gets doubled once per pair that encloses it, i.e. once per level of depth. No tree, no stack needed:

$$\text{score}(s) \;=\; \sum_{\text{innermost } \texttt{()}} 2^{\,\text{depth}}$$

where depth = number of pairs strictly enclosing that (). An innermost pair is spotted locally: a ) whose previous character is (. Outer pairs never score on their own — they only lift what's inside one level deeper.

Read the score off the depth profile

Walk (()(()))() keeping a depth counter. Every peak of the profile that is a single () is a scoring atom; its contribution is \(2^d\) where \(d\) is the depth after its ) (the level the peak sits on). The slopes in between contribute nothing.

Check by the rules: \(\texttt{(()(()))} = 2\,(1 + 2\cdot 1) = 6\), plus the trailing \(\texttt{()} = 1\), total 7 — exactly \(2^1 + 2^2 + 2^0\).

Same thing as a stack (the "honest" recursion)

If you don't trust the distributivity trick, evaluate the grammar directly. Keep one frame per open group holding the score of what's been closed inside it so far. ( opens a group: push 0. ) closes it: pop its inner score \(v\); the group is worth \(1\) if empty, else \(2v\), and that is added to the enclosing frame:

$$\texttt{(}:\ \text{push } 0 \qquad \texttt{)}:\ v \leftarrow \text{pop}(),\ \ \text{top} \mathrel{+}= \max(2v,\,1)$$

Green closes are innermost () (\(+1\)); orange closes wrap a non-empty group (\(\times 2\)). Each \(+1\) gets doubled once by every orange close above it — that's the \(2^{d}\) in the depth formula. The stack depth at any moment equals the depth counter, which is why the counter alone suffices.

Code

class Solution:
    def scoreOfParentheses(self, s: str) -> int:
        # Each innermost "()" at depth d contributes 2**d.
        ans = depth = 0
        for i, c in enumerate(s):
            if c == '(':
                depth += 1
            else:
                depth -= 1
                if s[i - 1] == '(':
                    ans += 1 << depth
        return ans

Complexity

One pass, one counter: \(O(n)\) time, \(O(1)\) space. The stack version is \(O(n)\) time, \(O(n)\) space; naive recursive splitting into balanced chunks is \(O(n^2)\) worst case.
