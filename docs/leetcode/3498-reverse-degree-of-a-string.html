3498. Reverse Degree of a String

Alphabet rank × position product

Insight

Reverse alphabet rank is \(\mathrm{rank}(c)=26-(c-\mathtt{'a'})\) (\(\mathtt{a}\to 26,\ldots,\mathtt{z}\to 1\)). The reverse degree is just \(\sum_i \mathrm{rank}(s[i])\cdot(i+1)\).

Contributions

Example s="abc": ranks \(26,25,24\) at positions \(1,2,3\) → products \(26+50+72=148\).

Each bar is one character’s contribution \(\mathrm{rank}\times\mathrm{position}\).

Code

class Solution:
    def reverseDegree(self, s: str) -> int:
        # reversed alphabet: 'a'→26 … 'z'→1; multiply by 1-indexed position
        return sum((26 - (ord(c) - ord("a"))) * (i + 1) for i, c in enumerate(s))
