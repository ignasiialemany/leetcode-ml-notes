3871. Count Commas in Range II

Threshold sum · O(log n)

Insight

Every threshold \(T \in \{10^3, 10^6, 10^9, \ldots\}\) adds one more comma to every integer \(\ge T\). So for each \(T \le n\) add \(n - T + 1\), then stop — \(n\) up to \(10^{15}\) needs only a handful of thresholds.

Contributions per threshold

Toy \(n = 2{,}000{,}000\): \(T=1000\) contributes \(1{,}999{,}001\); \(T=10^6\) contributes \(1{,}000{,}001\). Sum \(= 2{,}999{,}002\).

Each bar is \(n-T+1\). Larger \(n\) just keeps multiplying \(T\) by \(1000\) until it exceeds \(n\).

Code

class Solution:
    def countCommas(self, n: int) -> int:
        ans, t = 0, 1000
        while t <= n:
            ans += n - t + 1
            t *= 1000
        return ans
