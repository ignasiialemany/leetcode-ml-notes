11. Container With Most Water

Two pointers from both ends

Insight

Start wide. Area = (j−i)×min(h[i],h[j]). Always advance the shorter end — every remaining pair using it is worse.

1. Optimal container

For [1,8,6,2,5,4,8,3,7] the best is indices 1 and 8 → area 49.

2. Algorithm steps

First four pointer moves. Always kill the shorter side.

3. Area progression

Area is not monotonic — track a running best. Only O(n) pairs checked.

Code

class Solution:
    def maxArea(self, height):
        i, j, best = 0, len(height) - 1, 0
        while i < j:
            hi, hj = height[i], height[j]
            best = max(best, (j - i) * min(hi, hj))
            if hi <= hj: i += 1
            else: j -= 1
        return best
