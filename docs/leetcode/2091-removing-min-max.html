2091. Removing Minimum and Maximum From Array

Cover two positions from the ends

Insight

Only front/back deletes. After finding i_min and i_max, answer is min(both from left, both from right, one each). Remember +1 for 0-index.

Pattern

Cover two positions from the ends

Code

class Solution:
    def minimumDeletions(self, nums):
        n = len(nums)
        i_min = i_max = 0
        for i, x in enumerate(nums):
            if x < nums[i_min]: i_min = i
            if x > nums[i_max]: i_max = i
        a, b = sorted((i_min, i_max))
        return min(b + 1, n - a, a + 1 + n - b)
