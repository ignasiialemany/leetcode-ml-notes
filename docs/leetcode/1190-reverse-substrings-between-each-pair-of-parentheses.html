1190. Reverse Substrings Between Each Pair of Parentheses

Stack: reverse on matching close

Insight

Each matched pair means “reverse whatever is currently between these parentheses,” starting from the innermost pair. Brackets never appear in the answer. A character stack does this in one left-to-right scan: letters and ( push; on ), pop until (, discard the open, and push the popped characters back — popping already reverses them.

Innermost first

Example s="(ed(et(oc))el)": reverse oc, then etco, then the whole interior. The three reverses compose into leetcode.

Each close applies one reverse to the current interior. Outer pairs see the already-flipped inner material.

Stack on each close

For (u(love)i): the first ) pops love (as e,v,o,l), discards (, and pushes that chunk back. The outer ) does the same for uevoli → iloveu.

Popping into a temporary list reverses; extending the stack writes that reverse in place. No brackets survive.

Code

class Solution:
    def reverseParentheses(self, s: str) -> str:
        stack = []
        for c in s:
            if c == ')':
                chunk = []
                while stack and stack[-1] != '(':
                    chunk.append(stack.pop())
                stack.pop()  # discard '('
                stack.extend(chunk)  # already reversed by popping
            else:
                stack.append(c)
        return ''.join(stack)
