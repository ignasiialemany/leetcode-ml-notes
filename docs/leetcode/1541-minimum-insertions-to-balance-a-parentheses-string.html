1541. Minimum Insertions to Balance a Parentheses String

Greedy balance counter: each '(' owes two ')', fix odd need before a new '('

Insight

Here a ( is closed by two consecutive ). It's 921 with a twist: track need = how many ) are still owed. Each ( adds 2 and each ) pays 1. Two things can go wrong, and each costs one insertion:

  • Orphan ). A ) arrives when nothing is owed (need would hit \(-1\)). Insert a ( before it. That ( owes 2 and this ) pays one, so need becomes 1.
  • Odd need when a ( arrives. Odd need means the innermost ( has received exactly one ). The two closers must be adjacent, so a new ( can't sit between them. Insert the missing ) now (need -= 1), then open the new pair.

At the end, whatever is still owed gets appended:

$$\text{answer} = \text{ins} + \text{need}_{\text{end}}$$

Why parity is the right test: complete pairs always contribute an even amount to need, so need is odd exactly when one ( is half-closed. A ) arriving on odd need is fine because it finishes that pair. Only a ( arriving on odd need breaks adjacency. Both fixes are forced, since no later character can repair them, so greedy is optimal.

The parity view: when odd need forces a ')'

Now ()(()))(. Colour the counter by parity just before each character. Blue (even) means every open ( is either untouched or fully closed. Orange (odd) means one ( has received a single ) and is waiting for its partner.

Formally, write \(\text{need}\) before a ( at position \(i\). Then

$$\text{ins} \mathrel{+}= [\text{need}_i \bmod 2 = 1],\qquad \text{need}_{i+1} = \text{need}_i - (\text{need}_i \bmod 2) + 2$$

Code

class Solution:
    def minInsertions(self, s: str) -> int:
        ins = need = 0  # need = ')' still required
        for c in s:
            if c == '(':
                if need % 2:      # odd need: insert a ')' to close the pending pair
                    ins += 1; need -= 1
                need += 2
            else:
                need -= 1
                if need < 0:      # unmatched ')': insert a '('
                    ins += 1; need += 2
        return ins + need

Complexity

One pass, two counters: \(O(n)\) time, \(O(1)\) space. It's the 921 clamped counter with a cost of 2 per open plus a parity check. Compare 678 (a band of possible counts instead of one) and 20 (the stack version that the counter replaces).
