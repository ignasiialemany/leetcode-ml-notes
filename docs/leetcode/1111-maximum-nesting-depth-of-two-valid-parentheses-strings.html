1111. Maximum Nesting Depth of Two Valid Parentheses Strings

Assign nesting levels by parity (split VPS)

Insight

You must cut a valid parentheses string into two VPSs and minimize the deeper of the two. The optimal cut is almost free: walk a running depth and send odd levels to one group and even levels to the other. Each open is labeled with depth % 2 before you increment; each close is labeled with depth % 2 after you decrement. That puts consecutive nesting shells into different buckets, so each bucket’s depth is about \(\lceil D/2 \rceil\) of the original max depth \(D\).

Parity walk

For seq="(()())" the running depth hits 2. Coloring by group parity yields [0,1,1,1,1,0]: the outer pair stays in A, the two inner pairs go to B.

Blue = group 0, green = group 1. The label under each paren is the group bit written into the answer array.

The two VPSs

After the split, A is () (depth 1) and B is ()() (depth 1). The objective max(depth(A), depth(B)) is 1 — half of the original depth 2.

Any valid optimal coloring is accepted; parity of depth is the shortest way to build one.

Code

class Solution:
    def maxDepthAfterSplit(self, seq: str) -> list[int]:
        ans = []
        depth = 0
        for c in seq:
            if c == "(":
                ans.append(depth % 2)
                depth += 1
            else:
                depth -= 1
                ans.append(depth % 2)
        return ans
