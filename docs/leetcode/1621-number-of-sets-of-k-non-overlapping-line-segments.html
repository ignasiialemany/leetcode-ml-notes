1621. Number of Sets of K Non-Overlapping Line Segments

Combinatorial map: segments → C(n+k-1, 2k)

Insight

You have \(n\) points on a line; count ways to draw exactly \(k\) non-overlapping segments of positive length (sharing an endpoint is OK). A stars-and-bars / endpoint transform collapses the DP into one binomial:

$$ \mathrm{answer}(n,k)=\binom{n+k-1}{2k}\bmod(10^9+7). $$

Intuition: each segment needs two distinct endpoints; allowing zero-width gaps between segments (shared endpoints) is the usual “bars” slack that bumps \(n\) to \(n+k-1\). Check: \((4,2)\to\binom{5}{4}=5\), \((3,1)\to\binom{3}{2}=3\).

Visual

All five sets for \(n=4\), \(k=2\) on points \(1..4\). Blue then green; shared endpoints appear in A, C, D, E.

Interiors must not overlap; touching at an endpoint is allowed. Closed form \(\binom{n+k-1}{2k}\).

Code

MOD = 10**9 + 7

class Solution:
    def numberOfSets(self, n: int, k: int) -> int:
        # C(n+k-1, 2k) mod 10^9+7
        N, R = n + k - 1, 2 * k
        if R > N:
            return 0
        num = den = 1
        for i in range(R):
            num = num * (N - i) % MOD
            den = den * (i + 1) % MOD
        return num * pow(den, MOD - 2, MOD) % MOD
