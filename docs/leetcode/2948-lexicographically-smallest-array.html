2948. Make Lexicographically Smallest Array by Swapping Elements

Sort + cluster by gap

Insight

Swaps with |a-b|≤limit form hop-clusters. Sort values; cut when consecutive gap > limit; zip sorted values onto sorted original indices inside each cluster.

Pattern

Sort + cluster by gap

Code

class Solution:
    def lexicographicallySmallestArray(self, nums, limit):
        n = len(nums)
        ids = sorted(range(n), key=nums.__getitem__)
        ans = [0] * n
        i = 0
        while i < n:
            j = i + 1
            while j < n and nums[ids[j]] - nums[ids[j - 1]] <= limit:
                j += 1
            pos = ids[i:j]
            pos.sort()
            for k, p in enumerate(pos):
                ans[p] = nums[ids[i + k]]
            i = j
        return ans
