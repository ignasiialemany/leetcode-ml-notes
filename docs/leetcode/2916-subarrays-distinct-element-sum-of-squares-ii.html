2916. Subarrays Distinct Element Sum of Squares II

Sweep right end + range add / range sum (two Fenwick trees)

Insight

Same question as 2913, but \(n \le 10^5\), so the \(O(n^2)\) expand-right loop is dead. Sweep the right end \(j\) and keep \(f[i]\) = distinct count of \(\textit{nums}[i..j]\) for every left end \(i\le j\).

When \(x=\textit{nums}[j]\) arrives, it is new exactly for the left ends after its previous occurrence \(p\): \(f[i] \mathrel{+}= 1\) for \(i\in(p,j]\). We need \(\sum_i f[i]^2\), and a square is not range-additive, but its change is:

$$\sum_{i=p+1}^{j} (f_i+1)^2 - f_i^2 \;=\; 2\sum_{i=p+1}^{j} f_i \;+\; (j-p)$$

So keep one running scalar \(Q=\sum_{i\le j} f_i^2\), update it with a range sum of \(f\), then apply the range add. Answer \(=\sum_j Q_j\). Range add + range sum is two Fenwick trees (or a lazy segment tree): \(O(n\log n)\).

Each row is one right end j

Row \(j\) holds \(f[i]\) for subarrays ending at \(j\). The green box is the only part that changes when \(\textit{nums}[j]\) arrives: everything after the last copy of the same value. The orange number is \(Q_j\); the answer is \(1+5+9+23+32=70\).

Why the range sum is all you need

Each bar is \(Q_j\) split into the old \(Q\), the \(2\sum f\) term from the range sum, and the \(+\text{len}\) term. \((f+1)^2=f^2+2f+1\) turns a non-additive square into a range-sum query.

Code

class Solution:
    def sumCounts(self, nums: List[int]) -> int:
        # Sweep the right end j. f[i] = distinct count of nums[i..j].
        # When nums[j] arrives, f[i] += 1 exactly for i in (last[nums[j]], j].
        # sum f^2 over that range grows by 2*sum(f) + len, so we only need
        # range-add / range-sum: two Fenwick trees.
        MOD = 10**9 + 7
        n = len(nums)
        b1 = [0] * (n + 1)
        b2 = [0] * (n + 1)

        def upd(i: int, v: int) -> None:  # point update at 1-based i of diff array
            w = v * i
            while i <= n:
                b1[i] += v
                b2[i] += w
                i += i & -i

        def pref(i: int) -> int:  # sum f[1..i]
            s1 = s2 = 0
            k = i
            while k > 0:
                s1 += b1[k]
                s2 += b2[k]
                k -= k & -k
            return (i + 1) * s1 - s2

        last = {}
        sq = 0  # sum over i<=j of f[i]^2
        ans = 0
        for j, x in enumerate(nums, 1):
            l = last.get(x, 0) + 1  # 1-based range [l, j]
            s = pref(j) - pref(l - 1)
            sq += 2 * s + (j - l + 1)
            upd(l, 1)
            if j + 1 <= n:
                upd(j + 1, -1)
            last[x] = j
            ans += sq
        return ans % MOD
