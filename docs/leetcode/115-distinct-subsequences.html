115. Distinct Subsequences

Count ways along two sequences

Insight

State (i in s, j in t). Skip always; take on match. Put a pointer in the *target* on day one — generating all subsequences of s then filtering explodes.

Pattern

Count ways along two sequences

Code

class Solution:
    def numDistinct(self, s, t):
        m, n = len(s), len(t)
        dp = [[0]*(n+1) for _ in range(m+1)]
        for i in range(m+1):
            dp[i][0] = 1
        for i in range(1, m+1):
            for j in range(1, n+1):
                dp[i][j] = dp[i-1][j]
                if s[i-1] == t[j-1]:
                    dp[i][j] += dp[i-1][j-1]
        return dp[m][n]
