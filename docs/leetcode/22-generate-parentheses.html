22. Generate Parentheses

Backtracking: open/close counts (Catalan)

Insight

You do not generate then filter. Grow the string with two counters: place ( only while opens < n, place ) only while closes < opens. Every leaf of length \(2n\) is already a valid VPS — the prune rules are exactly the Catalan recurrence.

Decision tree (n = 2)

From the empty string, every branch that would close more than it has opened is cut immediately (red dashed). The two green leaves are (()) and ()() — Catalan(2) = 2.

Rules: opens < n to add (; closes < opens to add ); stop at length \(2n\).

Counters along one path

Building (()): the open counter rises to \(n\) first, then closes catch up. The shaded gap is the slack that keeps the prefix valid.

Same invariants as a running balance scan — just tracked as two integers instead of one.

Code

class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        ans = []

        def dfs(s: str, opens: int, closes: int) -> None:
            if len(s) == 2 * n:
                ans.append(s)
                return
            if opens < n:
                dfs(s + '(', opens + 1, closes)
            if closes < opens:
                dfs(s + ')', opens, closes + 1)

        dfs('', 0, 0)
        return ans

Complexity

Output size is the Catalan number \(C_n = \frac{1}{n+1}\binom{2n}{n}\). Time and memory are \(\Theta(C_n \cdot n)\) to emit the strings. For \(n \le 8\), \(C_8 = 1430\) — tiny.
