2267. Check if There Is a Valid Parentheses String Path

Grid path with paren balance (DFS + memo)

Insight

A down/right path from the top-left to the bottom-right always visits exactly \(m+n-1\) cells. That string is a valid parentheses string only if the length is even, the running balance never goes negative, and it ends at zero. So the searchable state is not just the cell \((r,c)\) — it is \((r,c,\text{balance})\), memoized.

Two valid paths

On the sample grid, more than one down/right walk works. One forms ()(()); another forms ((())).

Moves are only right or down. Different routes can still both be valid VPS strings.

Balance scan

Track balance the usual way: ( adds one, ) subtracts one. Any prefix below zero is dead; finishing off zero is dead.

For ()(()) the counter stays non-negative and lands on 0 at the exit cell.

Prune with remaining cells

After the current cell you still have \( (m-1-r)+(n-1-c) \) cells left. You need at least as many closers as your current balance, so if \(\text{bal} > \text{remaining}\) the branch cannot recover. Also reject an odd path length up front: \(m+n-1\) odd ⇒ impossible.

With \(m,n\le 100\), memo on \((r,c,\text{bal})\) stays comfortable — balance is at most the path length.

Complexity

States \(\le m\cdot n\cdot (m+n)\). Each does \(O(1)\) work after memo, so about \(O(mn(m+n))\) time and memory.
