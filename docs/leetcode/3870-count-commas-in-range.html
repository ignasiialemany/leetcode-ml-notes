3870. Count Commas in Range

Closed form · digit groups

Insight

US thousands separators first appear at 1,000. For n ≤ 10⁵ every integer from 1000 to n contributes exactly one comma, so the answer is max(0, n - 999).

Where commas appear

998–999 print with zero commas; 1,000–1,003 each add one. Running answer jumps from 0 → 1 → 2 → 3 → 4.

Code

class Solution:
    def countCommas(self, n: int) -> int:
        return max(0, n - 999)
