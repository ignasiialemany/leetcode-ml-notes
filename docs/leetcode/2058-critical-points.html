2058. Find the Minimum and Maximum Number of Nodes Between Critical Points

Extrema along a line

Insight

Critical = strict local min/max (ends never). Min distance = closest consecutive criticals; max = first vs last. Stream first/prev/min_gap for O(1) extra space.

Visual

Pattern

Extrema along a line

Code

class Solution:
    def nodesBetweenCriticalPoints(self, head):
        first = prev_c = None
        min_d = 10**9
        prev, curr, idx = head, head.next, 1
        while curr and curr.next:
            if ((curr.val > prev.val and curr.val > curr.next.val) or
                (curr.val < prev.val and curr.val < curr.next.val)):
                if first is None: first = idx
                else: min_d = min(min_d, idx - prev_c)
                prev_c = idx
            prev, curr, idx = curr, curr.next, idx + 1
        if first is None or prev_c == first: return [-1, -1]
        return [min_d, prev_c - first]
